# Slike za dokumentaciju

Ovde idu snimci ekrana koji se ugrađuju u `DOKUMENTACIJA.docx`. Dokument ih automatski
preuzima po imenu fajla; gde slika ne postoji, u dokumentu stoji označeno prazno mesto.

| Ime fajla | Šta treba snimiti | Odakle |
|---|---|---|
| `ci-zeleno.png` | Zelen CI pipeline | GitHub, kartica Actions, CI Pipeline nad `main` |
| `cd-zeleno.png` | Zelen CD pipeline sa post-deploy proverom | GitHub, kartica Actions, CD Pipeline nad `main` |
| `sonarcloud.png` | Rezultat analize sa pokrivenošću koda | SonarCloud, projekat `LukaC011_devOps` |
| `grafana-dashboard.png` | Dashboard sa tri metrike | http://localhost:3000, `CRM System Overview` |
| `zipkin-trace.png` | Trace kroz četiri servisa | http://localhost:9411, pretraga po `task-service` |
| `loki-logovi.png` | Logovi filtrirani po `traceId` | http://localhost:3000, Explore nad Loki datasource-om |
